# Local SMS Spam Classification

Individual course project by Alejandro Jimenez, student ID 70480.

The proposed project classifies public SMS messages as ham or spam and compares a small FP32 neural model with dynamic INT8 quantization. The targets are spam F1 >= 0.90, p95 CPU latency <= 50 ms and total deployed artifacts <= 5 MB.

[One-page project proposal](proposal.pdf)

The dataset and scope are proposed for instructor approval in Lab 6.
