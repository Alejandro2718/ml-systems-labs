# Machine Learning Systems Labs



Individual laboratory work by Alejandro Jimenez.



Each lab folder contains its report, source code, and results.

The project folder contains the course project.



Python version: 3.11.8.



Lab 1 includes baseline model measurements and a deployment budget comparison.

The remaining dependency issue is documented in lab01/report.md.

Lab 2 includes a neural network implemented with NumPy, gradient checks,
training comparisons, and forward and backward timing.

Lab 4 includes Adult data validation, training-only preprocessing,

graph inspection, traced inference and tensor-layout measurements.

Lab 6 includes YAML-driven training, MLflow runs, profiling, loading and
optimization studies, checkpoint recovery and an individual project proposal.
